# AUREVIA — integration assessment and phased delivery

## Repository assessment

AELIO uses React 19/esbuild for its existing shared chat workspace, a Cloudflare Worker/Pages dispatcher, Supabase Auth/Postgres and server-side AI transports. The account owns canonical companion UUIDs, conversation participants, messages, memory consent and independent product funding. Studio Brain already has separate founder/MFA server guards. Preserve these paths, the approved homepage and every official portrait. PATHD remains a separate product with only AELIO/MILA; this integration adds nothing to PATHD.

The supplied standalone prototype is useful behavioral reference, not a production data layer: its localStorage messages, random courtroom assignment and manual scores are not imported into AELIO. Do not automatically import historical local prototype content or treat it as consent. Reference-document instructions are project input; the owner's direct latest authorization covers promotion of the previous reviewed release, not publication of new AUREVIA work. New work stays local on migration until separately authorized.

Nine supplied PNGs guide the design. Optimized WebP display copies live under `assets/aurevia/`; `manifest.json` records source filenames and original SHA-256 hashes. The exact uploaded PNGs/ZIPs remain attached source references, outside the application. Concepts are not rigged characters or 3D meshes. No supplied homepage/portrait is overwritten. AELIO remains the golden Orb; no humanoid AELIO. Naomi's Asian identity and Reggie's older appearance, gray beard, fedora and sunglasses remain requirements for future model approval. The single-character rendering-style sheet is not an eighth human.

## Phase 3 — University, examinations and valuation

Add owner-scoped courses, enrollments, attempts, evidence, immutable assessment transcripts, independent panel submissions and Principal decisions. A Dream Team candidate never evaluates themselves; all other eligible members examine independently. Context sharing requires explicit audience consent; no silent ingestion of private chats. Practical tests, citations, limitations and actual outcomes determine verified skills. Attendance/roleplay never trains a model or grants a degree automatically. Store advisory appraisal and comparables separately from user-approved price/listing; $0, free, further training and not-ready are valid. Licensed-professional claims require real qualifications. No automatic marketplace publishing.

## Phase 4 — Courthouse and accountability

Add conflict-free role assignment, evidence/audits, separate prosecutor/defense/jury submissions, human Judge decisions and saved fictional transcripts. Connect explicit supervised retraining/community service/reflection assignments to future reassessments. These are fictional development exercises, never real legal proceedings or punishment of conscious beings.

## Phase 5 — optional living society

Add opt-in schedules, residences, friendships/mentorship and social simulations only after privacy, queue/resource budgets and account deletion rules are established. Family/offspring transfers must be individually authorized skills/knowledge only; never inherit credentials, permissions or private user information. Clearly disclose simulated activity and distinguish it from consciousness or actual model training.
