# uci_digits.npz: provenance

- **Content:** 1,797 handwritten digit images, 8×8 pixels, grey levels 0–16, with labels 0–9.
- **Original source:** "Optical Recognition of Handwritten Digits" (Alpaydin & Kaynak, 1998), UCI Machine Learning Repository. https://doi.org/10.24432/C50P49
- **Original license:** Creative Commons Attribution 4.0 International (CC BY 4.0). Attribution is required: E. Alpaydin, C. Kaynak, UCI Machine Learning Repository.
- **How this file was made:** exported from the copy bundled in scikit-learn 1.9.1 (`sklearn.datasets.load_digits`, BSD-3-Clause). The arrays were not modified.
- **Use in AELIO:** training and evaluation data for the AELIO Native vision prototype (Milestone D). No pretrained weights are involved.
