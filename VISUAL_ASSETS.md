# AELIO public site: visual system and assets

Updated 2026-10-29. Applies to the public site only. Studio Brain and My AELIO use their own styles and are not affected.

## How the pages are made
- Pages are generated by `_src/build.mjs` from `_src/content.mjs` (`npm run build`), written to `public/`.
- **Environments** (`_src/scenes.mjs`). Each section has its own scene, drawn in code (SVG, CSS and small canvases in `public/assets/scene.js`). Nothing has text baked into an image.

| Section | Scene | What moves |
|---|---|---|
| Home | Night ocean that continues the entrance. Your official Dream Beyond emblem floats above the water, with a reflection | Stars twinkle, clouds drift, water shimmers, the emblem hovers |
| Meet AELIO | Intelligence sphere (clean original photo plate) | Light motes, sphere pulse |
| Dream Beyond | Dusk mountain ranges with three glowing portals. The portals are links (Vision, Dream Spaces, Ecosystem) | Mist, clouds, portal glow |
| Technology | Compute hall in perspective, with AELIO Native at the core | Light pulses running to the core, rack lights |
| Create | Holographic studio: blueprint floor, wireframe building, sphere, waveform, terrain | Each object floats or animates |
| Our Values | Glass pavilion at sunset (clean original photo plate) with a luminous globe | Globe turns, light motes |
| Values subpages | Sunset city across water, trees | Clouds, trees, water |
| Agent Campus | Isometric night campus. **Every building is a link** to its area | Paths glow, trees sway |
| AELIO Live | Night plaza; agents orbit the marketplace tower | Orbits, ring pulses |
| Green Guardians | Green hills, trees in the breeze, a glass conservatory, a pond | Trees sway, mist, water |

- Subpages use their section's environment (with variations) plus their own focal artwork.
- Reduced-motion users get still frames.
- Canvases pause off-screen.
- **Entrance**: `public/assets/intro.js` with styles in `public/assets/cine.css`.
  - Silent, 4 s, once per browsing session.
  - Four ways out, each tested: Skip, Escape, a script timer, and a CSS-only timer that hides it at 4 s even if JavaScript stops.
  - Never shown with reduced motion. If `intro.js` can't load, it never appears.
- **Official emblem**: `public/assets/img/brand/dream-beyond-logo*.webp`, made from your uploaded artwork without changes.
- **Icons**: `public/favicon.webp`, `icon-16/32/48/192/512.png`, `icon-maskable.png`, `apple-touch-icon.png` and `manifest.webmanifest`.

## Photoreal scenes: generate them, then add them in Web Designer
No image generation was available while building this, so the scenes above are drawn in code. To use photographs, generate them to these specs. In **Studio Brain → Web Designer → Page images**, upload the image, choose the page, adjust the focus and darkness, preview, and publish. No code changes or redeploy are needed.

Every image: **2560 × 1440 or larger, landscape, no text, no logos, no buttons, no UI, no people's faces in focus**. Leave the left third calmer and darker, because the headline sits there. Warm gold, copper and chrome on deep black and navy.

## Rules that keep it honest
- No invented live numbers. Technology and Green Guardians say readings come only from real sensors inside Studio Brain.
- Pricing comes from the existing site copy, labelled **Proposed** with "Billing isn't enabled". The engine's billing configuration has no subscription price yet, so nothing on the page contradicts it.
- Every card and button goes to a real page or opens a real dialog.
